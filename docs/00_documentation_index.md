# Documentation Index

This folder contains detailed planning and architecture documentation for the **Fabric AI Customer Retention Platform** portfolio project.

The root `README.md` provides the high-level project overview for interviewers, reviewers, and anyone landing on the repository for the first time.

The documents in this folder provide the deeper project delivery artifacts that simulate a lightweight real-world requirements and scoping process.

## Documentation Strategy

The documentation is intentionally split into small, focused files instead of one long document.

This mirrors a lightweight real-world project approach:

- The `README.md` acts as the public-facing project front door.
- The customer scenario document captures the requirements discovery artifact.
- The scope document acts as the lightweight POC agreement.
- The architecture document explains how the technical design supports the business objective.

## Project Framing

This project is designed to demonstrate senior-level AI + Data Engineering architecture thinking using Microsoft Fabric.

It intentionally prioritizes:

- Data engineering fundamentals
- Feature engineering
- ML-based inactivity / re-engagement risk scoring
- Explainable customer risk profiles
- AI-ready curated data products
- Fabric Data Agent experience
- Clear assumptions, risks, limitations, and scope control

It intentionally avoids becoming a full production system or enterprise BI solution in the initial two-week POC.
